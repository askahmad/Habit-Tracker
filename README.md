# Habit-Tracker ⚡

**HabitPulse** — A sleek, interactive Daily Goals & Streak Tracking Dashboard built for personal productivity and habit consistency.

🌐 **Live Demo:** [https://askahmad.github.io/Habit-Tracker/](https://askahmad.github.io/Habit-Tracker/)

---

### ✨ Features
- 📊 **Visual Analytics & Streaks:** Real-time tracking of current and longest streaks.
- 🎯 **Daily Goals:** Quick check-ins with smooth micro-interactions and audio feedback.
- 🌙 **Dark & Light Themes:** Modern theme toggle with persistent preferences.
- 💾 **Local Persistence:** Automatic localStorage state saving so progress is never lost.
- 📱 **Fully Responsive:** Optimized layout for desktop, tablet, and mobile browsers.

---

### 🚀 Running Locally
Open `index.html` directly in any modern web browser or serve it using any local static file server.
