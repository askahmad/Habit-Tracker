# Habit-Tracker ⚡

**HabitPulse** is an elite, high-performance daily habits and streak-building web app engineered for everyday personal productivity, viral routine sharing, RPG gamification, and effortless daily consistency.

🌐 **Live Demo:** [https://askahmad.github.io/Habit-Tracker/](https://askahmad.github.io/Habit-Tracker/)

---

## 🚀 What Makes HabitPulse Famous, Impressive & Effortless

### 📸 1. "Share My Streak" / Social Story Card Generator (Viral Engine)
- **Instagram & Social Ready:** Generates a dark-mode 4:5 social card with your active streak flames 🔥, annual heatmap snapshot, player rank, and habit progress.
- **Download PNG or Copy Post:** 1-click download of a high-resolution canvas image or formatted tweet/post text.
- **🔗 1-Click Challenge URLs:** Share your routine with friends via URL hash (e.g. `#challenge=...`) so they can accept and import your exact challenge in 1 click!

### 🎮 2. RPG XP & Player Leveling System (WOW Gamification)
- **Earn XP for Discipline:** +15 XP per check-in, +50 XP for perfect days, +100 XP for streak milestones.
- **Ranks & Titles:**
  - *Lv 1–2: Seedling Striver 🌱*
  - *Lv 3–5: Momentum Builder ⚡*
  - *Lv 6–9: Streak Champion 🔥*
  - *Lv 10–15: Habit Master 🏆*
  - *Lv 16–24: Iron Will Titan 🛡️*
  - *Lv 25+: Ascended Grandmaster 👑*
- **Level-Up Fanfare:** Animated XP progress bar in header with sound celebration.

### ⏱️ 3. Integrated Habit Pomodoro & Focus Timer
- **Circular Countdown Timer:** Built-in timer with 5m, 10m, 15m, 25m (Pomodoro), and 45m presets.
- **Singing Bowl Completion:** Zen gong chime + confetti burst + automatically marks the habit completed for today upon finishing!
- **🎧 Ambient Focus Sounds:** Built-in Web Audio API synthesizer for **Gentle Rain 🌧️** and **432Hz Zen Drone 🧘** to stay in deep focus.

### 🎯 4. Minimalist "Today's Focus Mode" (Zero Friction)
- **1-Click Focus Switch:** Toggle from the full 7-day matrix to an ultra-clean, distraction-free card list of remaining goals for **Today**.
- **Big Tap Cards:** Touch-friendly buttons, streak counters, and instant timer launcher.
- **🎙️ Voice Quick-Logging:** Tap the mic and say *"Water and workout done"* to check off habits hands-free via Web Speech Recognition!

### 🧠 5. Behavioral Science & Habit Stacking (*Atomic Habits*)
- **Implementation Triggers:** Attach formulaic cues (e.g., *"After I pour morning coffee, I will Read 20 pages"*).
- **❄️ Streak Freeze Shield:** Protect your streak on rest or travel days without breaking momentum.

### 🌟 6. First-Time User Onboarding & Environment Setup Wizard
- **Personalized Setup:** First-time visitors are welcomed into a 3-step setup wizard to configure their name, life archetype, daily completion target (3, 4–5, or 6+ goals), and color theme.
- **6 Curated Life Archetypes:**
  - 💻 **Deep Worker & Builder** (Deep work sprints, top priorities, reading, hydration)
  - 🏃‍♂️ **High-Performance Athlete** (Strength workout, 10,000 steps, cardio, clean nutrition)
  - 🧘 **Mindful Zen Master** (Meditation, gratitude journal, digital sunset, natural sunlight)
  - 🌅 **5 AM Morning Titan** (Sunlight, make bed, morning mobility, priorities)
  - 📚 **Continuous Growth & Scholar** (Read 20 pages, code skill 30m, reflection, language)
  - ✨ **Holistic & Balanced Life** (Hydration, 8h sleep, 10k steps, top priorities)
- **+100 Starter XP Bonus:** Instant dopamine kickoff with celebratory confetti and sound upon launching routine.

### 📚 7. 24+ Curated Habit Templates Library & Custom Habits
- **Pillar Dimensions:** Fitness, Health & Vitality, Mindfulness & Calm, Deep Work & Productivity, Learning & Growth, and Nutrition Discipline.
- **1-Click Add:** Browse individual templates with live search and category pills, or import curated routine bundles.
- **Inline Custom Habit Creator:** Seamlessly add bespoke habits with custom icons, routines, categories, and *Atomic Habits* stacking cues.

### 📱 8. 100% Responsive Mobile Architecture (320px–4K)
- **Sticky Column Habit Matrix:** Smooth horizontal touch-scrolling with the habit title pinned on the left with backdrop blur and drop shadow.
- **Fixed Mobile Bottom Navigation:** Quick 1-tap switching between Matrix, Today Focus (with notification badge), 20+ Habits, Rank, and Mobile Hub.
- **Mobile Tools Hub Sheet:** Slide-up quick drawer for Pomodoro timer, ambient rain audio, streak sharing, backups, and environment re-tuning.
- **Touch-Optimized:** Minimum 44px touch targets and iOS safe area padding support.

## ⌨️ Power-User Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `N` | Open Create Habit Modal |
| `O` | Personalize Environment & Habits Setup Wizard |
| `T` | Jump back to Today / Current Week |
| `M` | Mark all habits complete for Today |
| `D` | Toggle Dark / Light Theme |
| `S` | Open "Share My Streak" Story Card |
| `P` | Open Starter Templates Library |
| `A` | Open Milestone Badges & Achievements |
| `B` | Open Data Backup / Export / Import |
| `1` – `9` | Quick-toggle daily goal for habit #1 to #9 |
| `Esc` | Close any open modal |

## 🚀 Running Locally
Simply open `index.html` directly in any web browser, or serve it using:
```bash
# Using python
python -m http.server 8000

# Or using npx serve
npx serve .
```
